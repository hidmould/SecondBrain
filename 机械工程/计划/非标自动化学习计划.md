# 一、先明确非标自动化核心门槛（你零基础，优先抓权重最高内容）

岗位核心能力排序（优先级从高到低）：

1. 机械制图识图 + SolidWorks 建模出工程图（硬门槛，企业必用）
2. 标准件认知（导轨、丝杆、气缸、电机、轴承、同步带等）
3. 基础传动、直线运动、夹紧定位简单机构原理
4. 简单气动基础（气缸选型、电磁阀、气路符号）
5. 基础装配常识、加工工艺简单认知
6. 加分浅接触：PLC 基础（学徒岗大多不强制，但有优势）

# 二、30 天极限学习规划（每天建议 6～8 小时，时间少直接缩减深度）

## 第 1 阶段：前 10 天 —— SolidWorks + 机械识图（重中之重）

目标：会画简单零件、装配体、投基础工程图，能看懂别人图纸

1. 前 3 天：机械制图基础
    
    - 学习：第一 / 第三视角（非标绝大多数**第三视角**）、尺寸标注、公差基础、剖视图、三视图
    - 资源：B 站免费机械制图公开课，不用深挖复杂形位公差，记住常用即可
    
2. 4～10 天：SolidWorks 实操（每天大量动手，只看不动手完全没用）
    
    必练内容：
    
    - 草图：约束、尺寸、修剪
    - 特征：拉伸、切除、凸台、旋转、简单阵列
    - 装配：插入零件、配合（重合、平行、同轴）
    - 工程图：投影视图、简单尺寸标注
        
        不要碰：曲面、复杂焊件、高级仿真、管路高级模块，浪费时间
        
        练习素材：标准件小零件、简单支架、小治具
    

## 第 2 阶段：11～22 天 —— 标准件 + 基础机构 + 气动（非标灵魂）

### 1）标准件认知（4 天）

不用死记复杂型号，掌握**长什么样、干什么用**

清单：

- 直线传动：线性导轨、滚珠丝杆、滑台模组
- 动力：气缸（笔形、薄型、手指气缸）、减速电机、伺服电机简单认知
- 紧固件：内六角螺丝、螺母、平垫弹垫
- 传动件：同步轮同步带、链条链轮
    
    学习方式：
    
    去**米思米 / 怡合达官网**，翻看目录，看零件简图、应用示意图，不用深究选型计算公式。

### 2）基础自动化机构（5 天）

只学最常用简易机构：

- 直线往复：丝杆滑台、气缸推拉
- 夹紧定位：手指气缸夹取、侧推定位块
- 升降、简单翻转小结构
    
    渠道：B 站搜 “非标自动化经典机构”，多看治具、小型输送设备视频，看懂运动逻辑即可，暂不计算受力。

### 3）气动基础（3 天）

掌握：气动符号、气缸工作原理、二联件、电磁阀基础认知

不用学复杂气路设计，看得懂简易气路图就行。

## 第 3 阶段：23～30 天 —— 整合 + 求职准备，浅尝 PLC（可选）

1. 综合小练习（4 天）
    
    找一个简易治具案例：比如气缸夹紧 + 滑台移位的小型工装，尝试自己建模装配，不用精细选型。
    
2. PLC 极简入门（3 天，可选，加分项）
    
    学徒岗极少要求会编程，仅需了解：PLC 控制气缸、电机简单逻辑概念，认识输入输出，不深入梯形图编程。
    
3. 复盘 + 面试准备（剩余天数）
    
    整理学习作品：几张自己画的零件 / 装配截图；准备问答：标准件用途、简单设备运动思路；定位求职方向：**非标机械学徒、机械助理**，不要投递正式设计师岗。
    

# 三、必须认清的现实限制（避免预期崩塌）

1. 设计需要大量**选型计算、强度校核、加工工艺经验**，30 天只能知道概念，无法实操。
    
    比如：丝杆负载校核、导轨寿命、板材厚度选择，这些靠长年项目积累。
2. 图纸规范、BOM 清单制作、跟加工 / 装配对接，都需要实战。
3. 一个月极限成果上限：能协助设计师画简单零件、整理标准件、打杂装配看图，**不能独立承担设备方案设计**。

# 四、高效学习建议（零基础避坑）

1. 拒绝纯看书：视频实操 > 纸质教材，软件必须每天上手
2. 不要贪多：复杂液压、机器人视觉、复杂伺服控制直接跳过
3. 资源推荐（免费）
    
    - 软件教学：B 站 SolidWorks 零基础教程
    - 标准件库：怡合达、米思米在线目录
    - 机构案例：短视频平台小型自动化设备实拍
    
4. 求职心态：放低预期，优先找愿意带学徒的小非标厂，前半年以积累现场装配、看图经验为主

# 五、如果你每日可用学习时间很短（2-3 小时）

30 天连入门都吃力，建议拉长周期到 2～3 个月，先保证 SolidWorks 和识图过关再谈其他。
