# 基于YOLOv8的轴承缺陷检测系统 —— 功能模块设计方案

## 一、系统整体架构

- **前后端分离**：SpringBoot + Vue + MySQL
- **前端三端分离**：用户端（检测操作员）、审核端（质检工程师）、管理端（管理员/AI工程师）
- **后端核心服务层**：统一提供RESTful API，集成YOLOv8推理、任务调度、大模型调用、数据持久化等

| 端/层 | 服务对象 | 核心职责 |
| :--- | :--- | :--- |
| 用户端 | 一线检测操作员 | 日常送检、实时检测、查看个人报告 |
| 审核端 | 质检工程师 / 标注员 | 复核AI预标注、管理数据集、驱动模型迭代 |
| 管理端 | 管理员 / AI工程师 | 模型训练运维、系统监控、全局数据决策 |
| 后端核心层 | 所有前端 | 算法推理、异步任务、大模型调用、数据存储 |

---

## 二、用户端（8大模块）

| 模块 | 核心功能 |
| :--- | :--- |
| 用户认证 | 登录、Token续期、密码修改 |
| 多源检测中心 | 单图/批量图片上传检测；离线视频逐帧检测；USB/网络摄像头实时流检测 |
| 检测参数配置 | 调节置信度阈值、IoU阈值、检测类别开关 |
| 检测结果可视化 | 原图叠加标注框、类别/置信度悬浮显示、严重程度色标 |
| 异步任务进度 | WebSocket推送视频/批量任务的实时进度与预估剩余时间 |
| 个人检测记录 | 按时间/类型/缺陷筛选历史记录，查看详情（原图、结果图、元数据） |
| 个人数据看板 | 月度检测总量、缺陷检出率、各类缺陷占比饼图、日趋势折线图 |
| AI智能问诊（轻量） | 一键生成缺陷诊断报告（缺陷描述 + 可能成因 + 处理建议） |

---

## 三、审核端（5大模块）

| 模块 | 核心功能 |
| :--- | :--- |
| 待审核任务池 | 展示置信度偏低或用户标记“存疑”的预标注任务，按优先级排序 |
| 智能标注修正器 | 加载原图与预标注框，支持拖拽调整框、修改类别、删除误检框、手动新增漏检框，确认/驳回 |
| 审核结果回流 | 审核通过的数据落库至“已标注训练集”，驳回的存入“待重新标注池” |
| 主动学习采样建议 | 基于置信度熵值，推荐高价值难例（模糊裂纹、光照异常等）优先审核 |
| 审核历史与统计 | 个人审核工作量统计、审核一致率、各类缺陷修正频率 |

---

## 四、管理端（8大模块）

| 模块 | 核心功能 |
| :--- | :--- |
| 用户与权限管理 | 用户CRUD、角色分配（操作员/审核员/管理员）、操作日志审计 |
| 模型仓库管理 | 上传/删除/切换YOLOv8/v10/v11等权重，记录元信息（mAP、速度），支持A/B测试 |
| 模型训练中心 | 训练参数配置（Epoch、Batch Size、学习率等），启动/停止训练，日志流式输出，训练曲线可视化（Loss、mAP、PR、混淆矩阵、F1），训练后自动对比性能并提示部署 |
| 算法增强配置 | 切换Backbone（原版/MobileNetV4/ShuffleNet）、启用注意力机制（CBAM/GAM）、选择Loss函数（CIoU/WIoU/Shape-IoU）、启用TensorRT/ONNX加速并展示FPS对比 |
| 数据集管理 | 数据集增删改查，训练/验证/测试集比例划分，标注信息统计 |
| 全系统检测监控大屏 | 实时检测量统计（今日/本周/本月），GPU利用率/显存/推理延迟曲线，全局缺陷占比Pareto图 |
| 工业质量分析（SPC） | 按产线/设备生成不良率排行榜，绘制缺陷率P-Chart控制图，自动标记异常波动点 |
| 系统运维配置 | 全局参数设置（上传大小、视频时长、超时时间），消息队列状态监控，操作日志导出 |

---

## 五、后端核心服务层（5大服务组）

| 服务组 | 核心组件 | 职责 |
| :--- | :--- | :--- |
| 推理引擎组 | YOLOv8推理服务、算法增强Wrapper、小目标/难例增强 | 加载PyTorch/ONNX/TensorRT权重，支持动态注入注意力/替换Backbone，针对微小裂纹进行切片放大或多尺度融合推理 |
| 任务调度组 | 异步任务队列（RabbitMQ/Redis）、GPU资源调度器 | 耗时任务异步处理，通过WebSocket推送进度；多GPU环境下动态负载均衡 |
| 大模型（AI）服务组 | RAG知识检索服务、智能诊断生成服务 | 构建缺陷-成因-对策向量库，调用DeepSeek/通义千问生成结构化诊断报告 |
| 数据持久化组 | MySQL数据服务、文件存储服务（MinIO/本地） | 所有结构化数据ORM操作；管理上传图片、结果图、视频切片、训练集文件 |
| 增量学习组 | 自动微调触发器、模型版本回滚 | 定时检测新审核数据量，达到阈值自动启动后台微调；性能下降时支持一键回滚 |

## 六、模块汇总

| 端/层 | 模块数量 | 核心亮点 |
| :--- | :--- | :--- |
| 用户端 | 8 | WebSocket实时进度、多源检测、轻量AI问诊 |
| 审核端 | 5 | 交互式标注修正、主动学习难例采样、数据回流闭环 |
| 管理端 | 8 | 训练可视化、SPC质量控制、GPU监控大屏、算法增强配置 |
| 后端核心层 | 5大服务组 | TensorRT加速、RAG知识检索、GPU负载调度、增量自动微调 |
